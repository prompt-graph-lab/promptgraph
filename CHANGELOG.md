# PromptGraph Pro Changelog

This file is the compact chronological release index. Detailed notes describe
user workflows and compatibility boundaries; the changelog is not a
commit-by-commit development log. Publication dates are recorded only when a
release is actually published.

## PromptGraph Pro 1.0.0

The 1.0.0 OSS release uses a vetted clean source tree and the MIT License.
PromptGraph-authored source code, documentation, and synthetic examples or
fixtures use Copyright (c) 2026 PromptGraph Lab.; see the
[license and attribution audit](docs/release-process.md#license-and-attribution-audit).

- Gallery-first illustration-sequence editing with Candidates, Variants,
  Workbench, Scenes, Trash/restore, Sequence Snapshots, and Sequence Preview.
- Graph Edit, Focus Edit, scoped batch prompt operations, reusable Project and
  Global Modules, Attribute Groups, and local AnimaDex import.
- Metadata-aware PNG/JPEG import, explicit ComfyUI generation, and portable
  Final Images Export manifest v2.
- Atomic Project JSON and Global Module Library replacement, with explicit
  overwrite confirmation for occupied Save As destinations.
- Exact runtime lock and reproducible Windows setup/launch. Optional archive
  packaging, if offered, remains separate from the source distribution.

See [PromptGraph Pro 1.0.0 release notes](docs/releases/1.0.0.md) and the
[backup, upgrade, rollback, and recovery guide](docs/backup-upgrade-rollback.md).
